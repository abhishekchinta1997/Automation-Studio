# 🚀 Automation Studio

**Automation Studio** is a professional, enterprise-grade Practice Web Application and QA Sandbox engineered specifically for practicing and mastering web test automation using industry-leading frameworks like **Playwright**, **Selenium**, and **Cypress**.

---

## ✨ Key Features

### 🔐 1. Authentication & Role-Based Access
* **Demo Credential Shortcuts:** Quick-fill login shortcuts for Super User, Admin User, and Test User roles.
* **Security Utilities:** Password visibility toggles, "Remember me" options, and password recovery modals.
* **Role-Based Routing:** Secure route protection guarding admin dashboards and testing labs based on user permissions.

### 📊 2. Admin Dashboard & Governance
* **Overview Metrics:** Track total users, active roles, locked accounts, and disabled profiles with modal inspection tables.
* **Audit Workflows:** One-click CSV, Excel, and PDF report exports alongside live telemetry audit logs.

### 🧪 3. Automation Lab (Interactive QA Sandbox & Live Inspector)
* **Form Controls:** Horizontal radio button groups, vertical checkboxes, range sliders, and text input submission triggers with interactive confirmation modals.
* **Dynamic Data Tables:** Searchable, sortable, and filterable records with row-selection tracking.
* **Async & AJAX Waits:** Simulated network latency, loading spinners, and asynchronous delay testing.
* **Frames & Storage:** Shadow DOM elements, nested iframes, LocalStorage token managers, and cookie inspection utilities.
* **Live Inspector Console:** Real-time telemetry feed logging user interactions, triggered event payloads, and execution timestamps side-by-side with test workspaces.

### 🛠️ 4. Test Case Builder & Code Generator
* **Multi-Framework Support:** Instant generation of production-ready test scripts for **Playwright (TypeScript)**, **Selenium WebDriver (Java)**, and **Cypress (JavaScript)**.
* **Resilient Selectors:** Promotes best practices by generating scripts using robust `data-testid` locators.
* **Copy & Export:** One-click code copying and file downloading (`.spec.ts`, `.java`, `.cy.js`).

### 🎨 5. UI & Ergonomics
* **Dynamic Theme Engine:** True Black Dark Mode (`#000000`) with neutral dark cards (`#121212`) and high-contrast white text (`#F9FAFB`), alongside a clean Light Mode.
* **Collapsible Sidebar:** Responsive sidebar toggle with collapsed icon-only view and hover tooltips.

## 🛠️ Tech Stack

* **Frontend:** React 18, TypeScript, Vite
* **Routing:** React Router DOM
* **State Management:** React Context API with persistent session simulation
* **Styling:** Custom CSS & Tailwind-inspired utility classes
* **Icons:** Lucide React
