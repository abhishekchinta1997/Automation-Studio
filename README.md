# Automation Practice App

Role-based React + TypeScript practice website for UI automation.

## Run
```bash
npm install
npm run dev
```

Open the Local URL shown in terminal.

## Logins
- Admin: `admin@example.com` / `admin123`
- Test User: `test@example.com` / `test123`

## Pages
- Login
- Admin Home
- Admin User Management
- Test User Home
- Unauthorized
- 404

All important elements include `data-testid` selectors.
